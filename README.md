## Como executar

### 1. Clone o repositório e entre na pasta do projeto
```bash
    git clone https://github.com/ticiaalm/Role-Radar
    cd role-radar
```

### 2. Instale as dependências
```bash
    npm install 
```

### 3. Preencha as duas chaves em `src/utils/chaves.js` e as substitua em `COLOQUE_SUA_CHAVE_AQUI`
- `GEOAPIFY.KEY`: Crie uma conta gratuita em https://myprojects.geoapify.com, crie um projeto e copie sua chave de API.
- `PRIMEUI_LICENSE`: Obtenha a chave da licença Community da PrimeUI em https://primeui.store/primeui.

### 4. Inicie a aplicação
```bash
    npm run dev
```

### 5. No terminal da aplicação, abra no navegador o endereço indicado - http://localhost:5173
Ao iniciar a aplicação, o navegador solicitará permissão para acessar sua localização. É necessário permitir o acesso para que a aplicação funcione corretamente.
